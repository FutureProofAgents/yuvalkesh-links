```bash

```

כל מה שכתוב מכאן קורה בתוך החלון הזה, על השרת. תכתבו את זה על פתק. זה יחסוך לכם שעה בהמשך.

## שלב 1: להתקין את OpenClaw

OpenClaw הוא המנוע. הוא מקבל הודעה מטלגרם, שולח אותה למודל, מריץ את הכלים, ומחזיר תשובה. קוד פתוח, נכתב על ידי פיטר שטיינברגר, יצא בנובמבר 2025. גרסה 2.0 יצאה ב30 באוגוסט 2026.

שלוש פקודות:

```bash
curl -fsSL https://openclaw.ai/install.sh | bash
openclaw onboard
openclaw gateway install
```

הראשונה מתקינה. השנייה פותחת אשף שמבקש איזה מודל ואיזה ערוץ. השלישית מגדירה את OpenClaw כשירות שרץ ברקע, גם אחרי שסוגרים את הטרמינל.

בסוף יש דשבורד על פורט 18789. הוא סגור לאינטרנט בכוונה. פותחים אותו רק מהמחשב שלכם דרך מנהרת SSH, בהמשך אראה איך.

## שלב 2: לחבר מודל בלי חשבון חדש

לא צריך מפתח API. OpenClaw יודע להתחבר למנוי ChatGPT שכבר יש לכם:

```bash
openclaw models auth login --provider openai --device-code
```

הפקודה מדפיסה כתובת וקוד. פותחים את הכתובת בטלפון, מקלידים את הקוד, זהו. מנוי Claude מתחבר באותה צורה.

שני דברים לדעת:

- הקוד פג אחרי 15 דקות. הטלפון ביד לפני שמריצים.
- אם הפקודה נתקעת בלי להדפיס כלום, מתחברים לשרת עם `ssh -tt` במקום `ssh`.

באמצע היום החלפתי מודל רק לשיחה בטלגרם עם הפקודה `/model` בתוך הצ'אט. ברירת המחדל של המערכת נשארה. ככה מתנסים בלי לשבור כלום.

## שלב 3: לחבר טלגרם

פותחים טלגרם, כותבים ל־@BotFather, שולחים `/newbot`, ושומרים את הטוקן שהוא מחזיר. אז על השרת:

```bash
openclaw channels add --channel telegram --token YOUR_BOT_TOKEN
openclaw gateway restart
```

שולחים לבוט הודעה כלשהי. הוא לא יענה עדיין. מאשרים אותו מהשרת:

```bash
openclaw pairing list telegram
openclaw pairing approve telegram CODE
```

אחרי האישור הראשון נעלתי את הבוט כך שהוא עונה רק למזהה טלגרם שלי. בוט שעונה לכל מי שמוצא אותו הוא לא עוזר אישי. הוא בעיה.

מכאן יש לכם סוכן שעונה בטלגרם. כל השאר זה להפוך אותו לשימושי.

## שלב 5: לחבר כלים עם Composio

סוכן בלי כלים הוא צ'אטבוט. Composio הוא שירות שמחבר את הסוכן לאלף אפליקציות בהתחברות אחת. אתם מאשרים בדשבורד של Composio אילו אפליקציות מותר, והסוכן משתמש בהן.

על השרת:

```bash
openclaw plugins install clawhub:@composio/composio
openclaw plugins enable composio
openclaw config set plugins.entries.composio.hooks.allowConversationAccess true --strict-json
curl -fsSL https://composio.dev/install | sh
composio login --no-skill-install
composio whoami
```

כשהפקודה האחרונה מציגה את החשבון שלכם, הסוכן מחובר.

אצלי השלב הזה לקח תשע שעות. הנה למה, כדי שאצלכם ייקח תשע דקות.

**התחברתי על המכונה הלא נכונה.** הרצתי `composio login` על הלפטופ. הסוכן גר על השרת. הפתק משלב 0 קיים בגלל השעה הזאת.

**קישור ההתחברות נשבר.** הפקודה מדפיסה קישור חד פעמי בתוך מסגרת. הטרמינל שלי היה צר, והתו האחרון נפל לשורה הבאה. הקישור לא עבד. הפתרון:

```bash
COLUMNS=200 composio login --no-browser --no-wait --no-skill-install
```

מעתיקים את הקישור השלם לדפדפן, מאשרים, וחוזרים לטרמינל עם `composio login --poll --no-skill-install`.

**הדבקתי מפתח בצ'אט.** הסוכן מחק את ההודעה, אמר שלא השתמש במפתח, ואמר לי לבטל אותו וליצור חדש. מפתח שנשלח בצ'אט נחשב חשוף. את המפתח החדש מזינים בשדה מוגן בתוך הדשבורד של OpenClaw.

**הדשבורד דורש טוקן.** כדי לפתוח אותו, במחשב שלכם:

```bash
ssh -N -L 18789:127.0.0.1:18789 root@YOUR_SERVER_IP
```

משאירים את החלון פתוח, ובדפדפן פותחים `http://127.0.0.1:18789`. את הטוקן לוקחים מהשרת עם `openclaw gateway auth-token --show` ומדביקים בהגדרות החיבור. בלעדיו הדשבורד מציג Offline, וזה מה שהוא צריך להציג לזר.

ב22:26 הסוכן פירט את החיבורים: ג'ימייל, Google Docs, Drive, Sheets, Slides, יומן, GitHub, Airtable, Stripe, Vercel, ActiveCampaign ו־Zoom. 12 שירותים. הכלל שהוא ניסח בעצמו: "לרובוט יש מפתחות, לא חסינות דיפלומטית." לקרוא מותר. לשלוח, למחוק או לחייב, רק כשמבקשים במפורש.
